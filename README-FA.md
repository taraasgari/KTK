# KTK — فقط اصلاح نام روی رول بنر صفحه اصلی

فقط فایل `KTK/static/images/katika-hero-product.webp` جایگزین می‌شود.

- در تصویر، عبارت انگلیسی روی بسته‌بندی از `KATIKA` به `KTK` تبدیل شده است.
- اندازه اصلی تصویر 1050×520 ثابت است.
- هیچ فایل کد، دیتابیس، رسانه آپلودی، پنل مالک، عکس دیگر، یا نام فارسی عوض نمی‌شود.
- از فایل تصویری قبلی، پیش از جایگزینی، بکاپ در پوشه `backups` خود پروژه گرفته می‌شود.

## نصب روی ویندوز
ZIP را در یک پوشه جدا استخراج کنید. PowerShell را همان‌جا باز کنید:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\INSTALL-UPDATE.ps1 -ProjectPath "C:\Users\Tara\Desktop\KTK"
```

برای اجرای سرور پس از نصب، `-RunServer` را به دستور اضافه کنید یا داخل پوشه پروژه:

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

کش مرورگر را با `Ctrl+F5` تازه کنید.

**نکته:** این آپدیت فقط تصویر پیش‌فرض هدر صفحه اصلی را تغییر می‌دهد. اگر تصویر اسلایدر را از پنل مالک جداگانه آپلود کرده‌اید، تصویر آپلودی تغییر داده نمی‌شود؛ آن را با تصویر اصلاح‌شده جایگزین کنید.
